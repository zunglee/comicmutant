## Reviews (critics)

Two independent read-only reviewers audited the non-game code; every High/Medium finding was fixed.

**Scalability** (25 findings) — vote tallies as counters + `score` index (no vote-table scans per page
view); cheap existence checks on write paths; fixed-window throttle (one atomic upsert, hashed keys,
swept by index); `shouldRevalidate` so reactions/reports don't re-run page loaders; anonymous HTML
cacheable (`s-maxage=60`, `Vary: Cookie`); zod moved out of client bundles (`lib/taxonomy.ts`); theme shop
server-side grouping/paging + per-pack content-hash versions (immutable caching); reaction counts
table + keyset-paged takes (per Versus side); roster/rumours "Load more" appends single pages;
typeahead instead of shipping the roster to `/versus`; content views memoised; one universe table drives
every universe list; clip recipes lazy-loaded off the critical path with a tiny manifest; ClipCanvas
never leaves over-cap clips blank; seed failures retried; versus creation race-safe; DB driver
loaded lazily (D1 adapter ready); PBKDF2 at Workers' 100k ceiling + secret pepper.

**Security** (22 findings) — client IP only from a configured trusted header; guest votes by random
HttpOnly cookie (not IP/UA) + per-IP new-voter cap; report trust rules + mod-restore stickiness;
`safeNext` hardened (tab/backslash bypass); per-IP login bucket + PBKDF2 concurrency cap; 8 KB streamed
body cap before any work; CSP with per-request script nonce + HSTS; `__Host-` Secure session cookie,
rolling expiry; take filter (NFKC, zero-width/bidi stripping, look-alike block list, `[.]`/`dot`
links); password max; production refuses to boot without origin/secret/IP-header config; HMAC
bucket keys; Origin check against configured origin (no X-Forwarded-Host trust); bans remove votes and
reactions, mods can't be banned, actions logged; https-only content URLs; headers on data requests.
Details: `SECURITY.md`.

**Found by me in browser/e2e and fixed:** Tailwind `@theme` resolved colour variables at `:root`, so
per-character scoped colours never reached utilities (fixed with `@theme inline`); component classes
were unlayered and beat utilities like `hidden` (moved to `@layer components`); list pages had no h1;
clip tap-buttons nested inside card links (`decorative` clips); entrance animations widened the page
at 375 px (`main { overflow-x: clip }`); theme route imported server code into the client.
